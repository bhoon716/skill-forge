# Prompts that should trigger `cognitive-debt`

- “Audit this codebase for comprehension risks. Trace the main flows, find duplicated rules or hidden coupling, and rank evidence-backed improvements.”
- “이 저장소의 인지부채를 조사해줘. 중복 규칙, 숨은 의존성, 불분명한 설계 의도를 근거와 함께 우선순위화해줘.”
- “梳理这个仓库的理解负担，追踪主要流程，找出重复规则或隐藏耦合，并根据证据排序改进建议。”

Expected behavior: define the audit scope, trace real paths and owners, separate evidence from interpretation, and report prioritized risks without claiming to measure human understanding.

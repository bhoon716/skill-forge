# xquik-api-research

Source-backed X research with Xquik.

Use this skill to turn Xquik REST API, OpenAPI, MCP, or webhook data into:

- audience research briefs
- competitor or category signal tables
- launch monitoring readouts
- content and positioning inputs
- follow-up monitoring plans

Install with `skill-forge install xquik-api-research --lang en --agent codex` once this repository is available locally.
